# Olivia's Website

To add an article:

1. Create a file on your computer called `yyyy-mm-dd-article-title.md` (The date will not appear in the article. This is just used for sorting. More recent articles appear at the top.)

2. Add **Heading** to the top:
```
---
layout: post
title: "Article Title"
---
```

3. Paste your article in. Replace any line breaks with `<br>` (Regular whitespace gets ignored). If you want any additional formatting, use [Markdown](https://www.markdownguide.org/basic-syntax/).

4. Navigate to [_/posts](https://github.com/darienyoder/olivia-website/tree/main/_posts), click Add File, choose upload.

5. It will ask you to write a commit message. Just type something brief about what you did so changes are easy to keep track of.<img width="400" alt="image" src="https://github.com/user-attachments/assets/2e64f895-ad22-4716-ad9f-eafef550d561" />

6. To add an image to the article, name the file `article-title.png`, navigate to [/assets/images/articles](https://github.com/darienyoder/olivia-website/tree/main/assets/images/articles), and upload the file like before.

7. It takes about two minutes for changes to appear on the website. Sometimes the formatting is wrong and you have to make little changes. If you have any questions, just ask Darien.
